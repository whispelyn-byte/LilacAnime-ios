# 데스크탑 0.5.51 반영

기준은 데스크탑 `7a23c8f`(0.5.51)와 iOS `23b102c`(0.4.25)입니다. 2026-10-24에 로컬 데스크탑의 `electron/`, `src/`가 이 기준 커밋과 같은지도 확인했습니다. iOS의 기존 변경을 유지하면서 그 이후 데스크탑 변경을 적용했습니다. 이 문서는 아직 배포하지 않은 변경을 설명합니다.

## 적용 내용

- **Miruro**: API를 영구 WebKit 세션에서 요청합니다. Cloudflare 확인이 필요하면 해당 사이트의 확인 창을 열고 완료 후 재시도합니다. 해결할 수 없는 차단은 별도로 알리며, 요청 취소와 시간 제한을 적용합니다.
- **RE:Anime · HLS**: 서버 선택 전 첫 미디어 조각의 재생 가능 여부를 확인합니다. AES-128로 암호화된 조각은 프록시·다운로드·Cast에서 변형하지 않습니다. PNG 등으로 위장된 비암호화 조각 처리는 유지합니다. 광고 판정은 URL 호스트와 경로를 검사하고 쿼리 토큰의 우연한 `ad` 문자열을 배제합니다.
- **한국어 제목 · Anissia**: 일본어 원제, 시즌, 방영일, 극장판 여부를 맞춘 한국어 제목 사전을 사용합니다. 일 단위 캐시와 이전 캐시 복구를 지원합니다. 제작자 링크가 Google Drive 폴더인 경우에도 자막 검색 경로에 포함합니다.
- **Whisper 음성 자막**: Tiny · Base · Small · Large v3 Turbo 모델을 직접 받은 뒤 일본어 음성을 기기에서 인식합니다. 30초 단위로 현재 재생 위치부터 처리하며 탐색 후 다음 작업의 우선순위를 바꿉니다. 인식 결과와 완료 구간을 저장해 이어서 처리하고, 새 자막이 생길 때 플레이어에 반영합니다. 자막이 없을 때 자동 시작, 수동 시작·중단, 다음 화 준비를 연결했습니다.
- **진행 중 번역**: 자동 번역 설정이 허용할 때 새로 인식된 줄을 기존 번역 엔진에 보냅니다. Gemini는 40줄씩 모으고 마지막 남은 줄은 종료 시 처리합니다. 클라우드 자동 번역 허용 설정을 그대로 따릅니다.
- **영상 정리**: 워터마크 영역과 영상에 박힌 자막 영역을 각각 최대 네 곳 지정할 수 있습니다. 데스크탑의 장면 학습 코드를 사용해 고정된 반투명 흰색 로고 마스크를 만들거나, 데스크탑 `.glsl` 마스크의 픽셀 데이터를 가져옵니다. 가져온 셰이더 코드를 실행하지 않고 검증한 데이터로 셰이더를 만듭니다. 영상 내장 자막은 밝기·외곽선 감지, 확장, 주변 픽셀 채우기의 세 단계로 처리합니다.
- **자막 줄 간격**: 80–300% 및 기본값 복원을 제공합니다. mpv의 세로 줄 간격 옵션에 적용합니다.

## iOS에서의 사용과 차이

- Whisper 모델은 **설정 > 자막 자동 번역 > Whisper**에서 다운로드·선택·삭제합니다. 모델을 받기 전에는 자동 음성 인식을 시작하지 않습니다. 모델과 마스크는 자막 임시 캐시와 별도 폴더에 저장합니다.
- 음성 인식은 WhisperKit 0.18.0과 Core ML을 사용합니다. 데스크탑의 실행 파일·프로세스 설치 방식은 사용하지 않습니다. 영상에서 음성을 추출하는 부분은 기존 FFmpeg 네이티브 연결을 사용합니다.
- 앱이 활성 상태이고 재생 가능한 영상이 연결되어 있을 때 음성 인식과 다음 화 준비를 진행합니다. iOS가 앱을 정지하면 작업 진행도 제한됩니다. 기기별 처리 속도·발열·메모리 사용량은 실제 기기에서 확인해야 합니다.
- 로고 학습은 재생 중 약 6분간 장면을 모읍니다. 학습 설정 화면을 닫으면 취소됩니다. 고정된 반투명 흰색 로고가 대상이며, 장면 변화가 부족하면 마스크를 저장하지 않고 이유를 표시합니다.
- 영상 정리는 mpv 화면에 적용됩니다. 원본 파일이나 다운로드 파일을 수정하지 않으며, 별도 시스템 재생·TV·원본 프레임 캡처 경로에는 같은 효과가 보장되지 않습니다.
- Electron 창 관리·OS 파일 대화상자·실행 파일 설치는 기존 iOS 화면·파일 선택·네이티브 플레이어로 대응합니다. 키보드 화살표 처리는 기존 iOS 플레이어 경로를 유지합니다.

## 검증

- JVM 공통 테스트 173개 통과(실패·오류·건너뜀 0).
- RE:Anime·Ohli 캡처와 워터마크 학습·마스크 파서의 Node 테스트 통과.
- iOS 테스트에 AES 암호화 범위와 다운로드 계획, 음성 구간 추출·취소, Whisper 탐색 순서·VTT, Miruro 확인/차단 분류, 마스크 검증과 줄 간격을 추가했습니다. 네이티브 빌드·테스트 결과는 PR의 **KMP and iOS** 체크에서 확인합니다.
- `docs/desktop-audit.json`의 117개 파일·124개 API 대응표를 갱신했습니다. 대응표는 코드 위치를 확인하는 자료이며 모든 외부 서비스의 실시간 동작을 보장하는 검증은 아닙니다.

실제 서비스의 Cloudflare 확인, 기기에서의 Whisper 인식 품질, 영상 정리 효과는 네트워크·콘텐츠·기기 상태에 따라 달라져 시뮬레이터 테스트만으로 확정하지 않습니다.
