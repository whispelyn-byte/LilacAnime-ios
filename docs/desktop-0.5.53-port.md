# 데스크탑 0.5.53 반영

비교 기준: 데스크탑 `39de49c`(0.5.52) → `ad341f4`(0.5.53), iOS `8952ee6`(0.4.26).

- 외부 키보드 ←/→ 탐색 시 이동한 쪽에 누적 이동 초와 도착 시각을 0.8초 표시합니다. 컨트롤 바의 표시 상태는 바꾸지 않습니다. 숫자 0–9 탐색은 가운데에 도착 시각만 표시합니다.
- mpv가 새 재생 위치를 보고하기 전에 연속 입력해도 마지막 요청 위치부터 이동합니다. 방향을 바꾸거나 안내가 만료되면 누적 초를 초기화하며, 영상 시작·끝을 넘지 않습니다. 잠금·설정 중 단축키 비활성화와 수동 탐색의 자동 스킵 제외 처리는 유지합니다.
- Linux AppImage 빌드·업데이트, Linux llama.cpp/Vulkan/CUDA 실행, 시스템 글꼴·mpv·bsdtar 탐색은 데스크탑 전용입니다. iOS는 기존 네이티브 빌드·SideStore 업데이트, Metal 로컬 AI, 앱 글꼴·mpv·libarchive를 사용하므로 이식하지 않습니다.
- `docs/desktop-audit.json`의 파일·API 대응 기준과 해시를 0.5.53으로 갱신했습니다.

검증: 반복 입력의 비동기 위치 처리, 방향 전환, 만료, 영상 경계, 숫자 탐색·알 수 없는 길이를 XCTest로 확인합니다. 전체 iOS 빌드와 테스트 결과는 해당 커밋의 KMP and iOS 워크플로에서 확인합니다.
