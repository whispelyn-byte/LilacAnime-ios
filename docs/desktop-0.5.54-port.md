# 데스크탑 0.5.54 반영

비교 기준: 데스크탑 `ad341f4`(0.5.53) → `e4ac622`(0.5.54), iOS `8f47b30`.

- Miruro 인증 창, 인증·차단 HTML 판별과 인증 대기·쿨다운을 제거했습니다. 목록·회차·영상 요청은 영구 데이터 저장소의 숨은 Miruro 웹페이지에서 보내며, 취소·시간 제한·응답 크기 제한·허용 주소 검사·미러 재시도를 유지합니다.
- 공통 웹뷰의 새 창 차단 오버라이드를 제거하고 영상 탐색·제목 검색·WinPNG 처리를 기존 WKWebView 생성 방식으로 복원했습니다. 데스크탑처럼 숨은 Miruro 페이지에만 전용 팝업 차단을 둡니다.
- 탐색 후 영상이 다시 진행될 때 컨트롤 바를 띄우지 않는 수정은 iOS의 기존 상태 처리와 일치합니다. MPV_EVENT_PLAYBACK_RESTART는 컨트롤 표시나 일시정지를 바꾸지 않고 버퍼링은 paused와 별도로 관찰합니다. 0.5.53의 키보드 탐색 안내와 연속 입력 처리도 유지합니다.
- Linux AppImage → .deb 및 apt/pkexec 업데이트는 데스크탑 전용입니다. iOS의 IPA·SideStore 배포에는 변경할 부분이 없습니다.
- 데스크탑에서 삭제한 provider:play/linkkf:play는 사용하지 않던 별도 Electron 창 API입니다. iOS의 실제 웹 플레이어 전환은 사용하는 기능이므로 유지합니다. 대응표에서는 삭제된 두 API와 폐기한 인증·전역 팝업 파일을 제외했습니다.
- docs/desktop-audit.json을 0.5.54의 115개 파일·122개 API 기준으로 갱신했습니다.

검증: Miruro 숨은 페이지의 팝업 차단·웹뷰 설정 보존과 일반 웹뷰의 독립성을 XCTest로 확인합니다. 기존 주소 허용 검사·키보드 탐색 회귀 테스트를 유지하고, 공통 테스트에 403 응답의 미러 재시도를 추가했습니다. 전체 빌드·테스트는 해당 커밋의 KMP and iOS 결과를 확인합니다.
