# 데스크탑 0.5.57 이후(0476623)까지 반영

비교 기준: 데스크탑 `0853a54`(iOS에 반영한 8b8fe70과 같은 내용) → `0476623`(0.5.56, 0.5.57과 그 뒤 수정 3개, 재생 막대 미리보기 포함), iOS `49a04fa`(0.4.28).

## 반영한 것

- **매일 바뀌는 추천**: 홈 위쪽 추천을 하루에 다섯 작품씩 고릅니다. 이번 시즌 신작 · 지금 방영 중 · 인기 작품 목록에서 번갈아 고르고, 작품마다 어느 목록에서 왔는지 표시합니다. 같은 날에는 같은 작품이 나오고, 시청기록에 있는 작품은 뺍니다(안 본 작품이 3개 미만인 목록은 그대로 씀). 섞는 방식(mulberry32, 앞 40개)과 날짜 계산(현지 시간)은 데스크탑과 같습니다. 방영 중 목록은 편성표에서 오늘을 볼 때 받은 것만 써서, 다른 요일을 눌러도 추천이 바뀌지 않습니다.
- **정렬 기억**: 홈의 이번 시즌 신작 / 최근 업데이트와 내 목록의 저장순 / 회차 업데이트순을 앱을 다시 켜도 기억합니다. 업데이트 목록이 없는 소스에서는 이번 시즌을 보여 주되 고른 값은 남겨 둡니다.
- **설정 > 일반 > 시작 화면**: 앱을 켰을 때 처음 보일 화면을 홈 · 전체 · 시청기록 · 내 목록 중에서 고릅니다.
- **자막 싱크 · Whisper가 영상을 읽는 동안의 미리 받기**: 두 기능은 플레이어와 같은 로컬 프록시에서 FFmpeg로 영상을 읽습니다. 이제 이 요청을 `LilacAnime-Background` User-Agent로 구분해, 플레이어가 이미 받은 조각은 그대로 쓰고 새 조각은 플레이어 캐시와 따로 받습니다. 플레이어가 아무것도 기다리지 않을 때만 2개까지 앞서 받습니다. 전에는 처음부터 끝까지 읽는 이 요청이 플레이어 캐시(16개)를 밀어내며 플레이어가 미리 받아 둔 조각을 취소할 수 있었습니다. 데스크탑에서 1.25배속 재생이 멈추던 원인과 같은 구조입니다.
- **시즌 판별**: 영어 제목 중간의 서수("the 7th Prince")를 7기로 읽지 않습니다. 서수는 제목 끝이나 부제 앞(`~ - ( : !`)에 있을 때만 시즌으로 봅니다. 환생했는데 제7왕자라 등의 Anissia·커뮤니티 자막 검색이 맞는 시즌을 찾습니다.
- **오래된 Tistory 첨부**: 주소에 확장자가 없는 `t1.daumcdn.net/cfile/tistory/…` 첨부도 링크 글자가 자막·압축 파일 이름(`… 07.smi`, `… .rar (1.2MB)`)이면 자막 링크로 씁니다.

- **재생 막대 미리보기**: 재생 막대를 끄는 동안 손가락 아래 위치의 장면과 시간을 막대 위에 보여 줍니다. 데스크탑의 두 번째 `<video>` 대신 `NativeAudio`의 `LilacFrameReader`가 플레이어와 같은 주소(로컬 프록시 또는 받은 파일)를 FFmpeg로 따로 열어, 그 위치의 키프레임부터 2.5초 안쪽 장면 한 장을 320×180으로 디코딩합니다(루프 필터·비참조 프레임 생략). 손가락이 0.12초 머문 뒤에만 읽고, 5초 칸마다 한 장(최대 90장)을 기억해 되돌아가면 바로 보입니다. 프록시는 이 요청을 `LilacAnime-Preview`로 구분해 플레이어 뒤에서 처리하고 앞서 받지 않습니다. 회차가 바뀌거나 플레이어를 닫으면 리더를 닫습니다.

## 이미 같거나 iOS에 해당하지 않는 것

- **자막 소스의 Linkkf**(51921e4): iOS 설정은 처음부터 Linkkf를 따로 두지 않고, 플레이어에서 Linkkf를 고르면 자동으로 저장하며, Linkkf 회차를 볼 때만 Linkkf 칩을 보입니다.
- **Whisper 칩 이름 '음성 인식'**: 8b8fe70 반영 때 같은 문구로 바꿨습니다.
- **FlixCloud 프레임 시간 보정·hls.js 복구**(76b5206, 0.5.57): Chromium MSE가 시간 간격이 거의 0인 프레임 뒤의 키프레임 없는 조각을 버리고, hls.js가 그 조각만 다시 받아 같은 구간을 반복하던 문제입니다. iOS는 mpv(FFmpeg)가 조각을 이어서 읽어 디코딩하므로 이 경로가 없습니다. 데스크탑의 보정은 프록시에서 영상 데이터를 고쳐 쓰는 것이라, 문제가 확인되지 않은 iOS에는 넣지 않았습니다.
- **자막 줄 간격 잘림**(0476623): Chromium 자막 상자가 넘치는 글자를 자르던 문제입니다. iOS는 libass가 그리므로 해당 없습니다.
- **포스터 아래 그림자 끄기**: iOS 포스터 카드에는 아래 그라데이션이 없습니다.
- **탭 밑줄·한국어 제목 검색 표시·밝은 테마 배너**: 데스크탑 CSS 전용 모양입니다.
