Linkkf 자막은 Linkkf 칩, 다른 사이트 트랙은 트랙 칩에 따로 나옵니다. 칩과 목록 제목은 트랙이 온 사이트("Re:Anime·Miruro")로, 다른 사이트 트랙에는 사이트 이름이 붙습니다.

- **싱크**: 다른 사이트 트랙은 다른 영상에 맞춘 것이라 싱크 기준(`SubtitleAutoSync.referenceTracks`)에서 빼고, 그 트랙 자막은 이 영상 음성으로 맞춥니다.
- **번역 원문 순서**: 사이트 일본어 → Jimaku → 다른 사이트 일본어 → 사이트 영어 → 다른 사이트 영어. 아직 오는 중인 다른 사이트 트랙은 Jimaku 다음에 기다립니다(최대 15초).
- **영상 서버**: Animenosub · Miruro는 다른 사이트에 한국어 트랙이 있으면 블로그 자막을 찾았을 때처럼 RAW를 고릅니다(먼저 찾은 쪽이 결정, 8초 제한 유지). 다운로드와 다음 화 미리 준비도 같습니다.
- **다운로드**: 다른 사이트 트랙을 사이트 정보(`origin`)와 함께 저장합니다. 다른 사이트 한국어 트랙은 저장 한국어 자막 다음, 블로그보다 먼저 회차 자막이 됩니다. 영상에 한국어가 박힌 회차는 트랙만 저장하고 띄우거나 번역하지 않습니다. 번역본 원문은 플레이어와 같은 순서입니다. 데스크탑에서 가져온 다운로드의 `crossSite`/`origin`도 읽습니다.
- **다음 화 미리 준비**: 다음 화의 다른 사이트 트랙에 한국어가 있으면 그 트랙으로 열리므로 블로그 검색 · 미리 번역을 하지 않습니다.
- **설정**: 플레이어 설정 > 자막 > **다른 사이트 자막 트랙도 찾기**(기본 켜짐). 끄면 플레이어 · 다운로드 · 다음 화 미리 준비 모두에서 찾지 않습니다.
- **Animenosub 상세**: 다른 이름 줄에서 일본어 원제를, 정보 상자의 Season(없으면 Released)에서 연도를 읽습니다.
