# Desktop → iOS 이식 목록

기준: [LilacAnime-desktop 0.5.6](https://github.com/whispelyn-byte/LilacAnime-desktop/tree/d7d4ec4) 및 로컬 후속 커밋 `5914a9b`(상세 카탈로그 필터·자막 싱크 입력).
데스크탑 preload의 콘텐츠·자막·번역·다운로드·업데이트 작업을 아래 네이티브 기능으로 대응했습니다. Electron 창을 iOS 안에서 실행하는 구조는 아닙니다.

## 기존 기능·데이터 보존

데스크탑의 홈·전체·검색·시청기록·내 목록·설정 구성이 기본입니다. iPad에서는 사이드바와 본문을 함께 표시하고, iPhone에서는 메뉴로 전환합니다. 이전 버전은 기존 릴리즈와 Git 이력에서 확인할 수 있습니다.
기존 library.json, 즐겨찾기, 시청 기록, 자막 싱크, API Keychain, 수동 모델 가져오기·Hugging Face 검색, mpv/ASS, Cast/PiP 기능을 유지합니다. 새 설정 필드는 optional로 추가해 이전 JSON을 읽습니다.
새 이름 인덱스·저장 자막·모델 메타데이터는 별도 저장하며, 설정 초기화나 보관함 자동 삭제를 하지 않습니다.
업데이트는 기존 앱을 지우지 않고 같은 Bundle ID/서명 계정으로 SideStore에 가져옵니다.

## 운영체제에 따른 대응과 차이

- PC 창 제목줄/창 버튼/멀티 윈도우는 iOS 내비게이션·전체 화면·회전으로 대응합니다.
- CUDA/Vulkan AI 가속은 Metal/CPU로 대응합니다. 프리셋은 같지만 기기 메모리 때문에 모든 대형 모델의 실행을 보장하지 않습니다.
- PC의 항상 열려 있는 외장 다운로드 폴더는 파일 앱을 통한 폴더 내보내기/가져오기로 대응합니다. 가져온 회차는 앱 저장 공간에 복사해 재생합니다.
- iOS에서 앱의 자체 설치/재서명은 제공할 수 없어 IPA 받기와 SideStore 업데이트로 대응합니다.
- iOS가 앱을 중단하면 카탈로그·번역·분석은 앱을 다시 열어 이어갑니다. 영상·모델 전송에는 background URLSession을 사용합니다.
- API의 소진 모델 제외 시간은 데스크탑과 같이 Gemini PerDay는 태평양 자정, 분당 제한/busy는 5분, 다른 공급자는 1시간입니다.
- ASS는 mpv에서 렌더링합니다. 시스템 PiP/AirPlay는 같은 외부 자막 표시를 제공하지 않으며, Cast는 VTT로 변환해 스타일 효과를 보존하지 않습니다.
- 암호화/분할 압축 자막과 모든 RAR 압축 변형을 약속하지 않습니다. 추출할 수 없는 파일은 오류를 표시합니다.
- PC의 downloads.json과 iOS의 index.json을 각각 읽습니다. PC 파일은 선택한 폴더로 경로를 연결한 뒤 앱 저장 공간에 복사합니다.

## 검증

공통 테스트: 파서·자막 타이밍/스타일·시즌/누적 회차·이름/호칭·모델 프롬프트·번역 모델 대체·과금 quota·캐시·홈의 공개된 회차 필터·소스 필터 경로·일별/분당 quota 대기 시간.
네이티브 테스트: 이전 설정 JSON, 시청 기록/회차 suffix, 실제 Gemma 4/ChatML Jinja, 실제 tiny GGUF CPU 추론·재사용·metrics, ZIP/7z/RAR/CP949·추출 경로, 폴더 이전의 HLS 자산 및 resume 제외, PC Windows 경로 이전·자막/폰트/OP·ED와 경로 검증, 기존 LAN/HLS 테스트. UI 테스트는 상세→가로 전체 화면→설정→뒤로 동작을 확인합니다.
Actions는 KMP iOS 테스트·iPhone 테스트·iPhone/iPad 예시 캡처와 unsigned arm64 IPA를 생성합니다. 최신 통과 실행 링크는 [KMP_IOS.md](../KMP_IOS.md)에 기록합니다.

대형 Gemma/Aya/Hy-MT2의 실기기 Metal 추론, 번역 품질·메모리, 외부 사이트의 실제 영상/첨부·로그인/캡차, SideStore 설치/폴더 앱 제공자/백그라운드 복귀, Chromecast 실물 동작은 아직 실기기 확인이 필요합니다. tiny GGUF는 런타임 동작 검증이며 대형 모델 성능 검증이 아닙니다.

## 플레이어 설정과 iPad 화면 모드 (iOS 리비전 5)

- 데스크탑처럼 영상 위 오른쪽에 설정 패널을 표시합니다. 재생/자막/자막 모양 탭, 화질·배속·화면 비율 버튼, 그룹별 스크롤을 사용하며 배경 탭이나 닫기로 복귀합니다.
- 재생 기본값은 1080p·1배속·10초 탐색·다음 화 자동 재생 켜짐·OP/ED 버튼 켜짐·자동 건너뛰기 꺼짐입니다. 저장한 설정은 덮어쓰지 않습니다.
- 맞춤은 원본 비율을 유지하고, 채움은 비율을 유지하며 가장자리를 자르고, 늘림은 여백 없이 전체 화면으로 늘립니다. 화면 맞춤 선택 시 이전 비율 선택을 정리하고 전역 설정과 같은 값을 저장합니다.
- Metal 영상 영역을 화면 크기로 유지하고 mpv의 video-aspect-override/keepaspect/panscan으로 영상과 자막의 비율·잘라내기를 처리합니다. 설정한 비율 때문에 채움이 무시되거나 SwiftUI 영상 영역이 이전 크기로 남던 문제를 제거했습니다.
- 배속 3x/4x, 건너뛰기 버튼 표시 설정, 0.25초 싱크 버튼 및 TTF/OTF/TTC 파일 앱 가져오기. 기존 자막 검색·번역·저장·오디오·다운로드·Cast/PiP를 유지합니다.

## 최근 데스크탑 변경 반영 (iOS 리비전 4)

- 소스 전체 카탈로그에 상세 장르·형식·연도·분기 필터 적용/초기화. 소스별 지원 항목만 표시하고 실제 API/분류 페이지를 조회하며, 빈 필터 결과 페이지에서도 다음 원본 페이지 탐색을 유지합니다.
- ReAnime 최신/인기/평점 정렬 API와 Animenosub 장르 ID·분기/연도 taxonomy 반영. 기존 전체 목록 수집·재개 및 한국어 제목 인덱스를 보존합니다.
- 원본/16:9/21:9/4:3/화면 채움 비율. 기존 화면 맞춤 설정은 새 비율을 선택하기 전까지 유지합니다.
- 재생 중 화면 0.4초 이상 누르기 또는 Space 길게 누르기로 2배속. 놓기·일시정지·화면 이탈 시 복원하며, 사용자가 중간에 고른 배속은 유지합니다. Space 짧게 누르기는 키를 뗄 때 재생·일시정지합니다.
- 자막 싱크 밀리초 직접 입력·초기화, 이전 ±120초 제한 제거. 일반 텍스트 자막은 mpv의 글꼴 크기와 좌우 여백으로 표시 폭을 제한하며 ASS는 기존 렌더러를 사용합니다.
- iPad 사이드바 기본 표시와 검색창 왼쪽 메뉴 버튼 복구. 좁은 화면에서는 같은 버튼으로 메뉴를 엽니다.

## 기존 기능의 데스크탑 동작 반영 (iOS 리비전 3)

- 홈 추천·상세 보기/내 목록, UP·월~일 방영 일정, 시즌/방영 중/인기/PV/극장판/16+와 전체 보기.
- 전체 화면의 소스별 기본/인기/최신/평점 정렬 기억; 공통 검색창 연결과 화면 안의 필터 적용/초기화.
