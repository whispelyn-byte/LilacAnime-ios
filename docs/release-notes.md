- Blogger 목록을 일부만 받으면 기존 캐시를 보존하고 다시 시도합니다. 같은 회차의 대체 링크와 다중 회차 묶음, 12.5화 검색/파일 선택을 보완하고 첨부 실패 후 갱신된 링크를 확인합니다.
- Anissia의 다른 시즌 게시물 차단, 같은 제작자의 대체 게시물·갱신된 링크·별칭 제목 처리를 보완했습니다.
- 애니24·링크애니 회차 날짜·업로드 수·총화수와 극장판 단일 회차를 보완했습니다. 원제·방영 연도로 AniList/MAL ID를 연결해 OP/ED 구간을 조회합니다.
- Gemini 응답 스키마·Thinking 옵션과 단순 요청 대체, 분당 제한 재시도·일일 한도 전환, Qwen/OpenAI 기본 모델과 대체 순서를 맞췄습니다. 빈 응답은 더 단순한 요청으로 다시 보냅니다.
- 번역 일부가 누락돼도 다른 줄은 계속 처리하고, 마지막에는 원문이 섞인 결과를 사용할 수 있습니다. 미완료 결과를 완료 캐시로 저장하지 않으며, 공급자별 모델·대체 옵션·키 변경을 캐시에 반영합니다.
- HLS 영상·오디오의 공유 키/초기화 조각 경로, 재시도 바이트 누적과 동시 전송 속도 표시를 수정했습니다. 중단한 작업의 앱 재시작 후 자동 재개를 막았습니다.
- 한국어 자막의 BOM/UTF-8/EUC-KR 해석 순서와 직접 다운로드한 GGUF의 헤더 검증을 보완했습니다. 기존 설정·기록·자막·키를 보존합니다.

# 0.4.0 iOS 리비전 6

Android와 같은 **0.4.0**, iOS 빌드 **36**입니다. 데스크탑 **0.5.9**의 제목 검색 재시도·자막 정렬·길게 누르기 동작을 비교·반영했습니다.

- 애니24에서 6초 광고를 본편으로 선택하던 문제 수정. 선택된 플레이어의 설정 응답·master.txt·확장자 없는 /m3 재생목록을 같은 웹 세션에서 읽고 본편 HLS·MP4를 검증합니다. 모바일 웹 플레이어 시작 여부에 의존하지 않으며 높은 화질부터 확인합니다. HTML 확장자 영상 조각은 재생·다운로드·Cast에서 처리하고, 본편을 넘긴 뒤 숨겨진 웹 영상을 멈춥니다.
- 자막 선택 순서, 자체 한국어 트랙과 커뮤니티/AI 우선순위, 20초 한국어 자막 제안, 작품별 AI 선호 기억, Jimaku 일본어/영어 대사 선택을 데스크탑 기준으로 조정했습니다.
- Csora 회차·누적 회차·묶음 자막과 별도 폰트 선택, Anissia WinPNG 이미지 자막 변환, 한국어 대체 제목·시즌/OVA/스페셜 표기를 보완했습니다.
- 번역 지시문·JSON ID·부분 응답/누락 재시도·seek 우선순위, 중·일 이중 자막 처리, 로컬/API 대체와 다음 화 클라우드 번역 opt-in 반영.
- 다운로드의 동시 전송·재시도, 원본/번역 자막·폰트·표지·AniSkip 보관, 자체 한국어의 중복 번역 방지, 일시 중지 직후 새 대기열 보존.
- 최근 회차 갱신·즐겨찾기 순서·Miruro 시작일 정렬·공개 회차 표시, RAW/SOFT 서버 선택, HLS 검증/선행 캐시와 앞뒤 5분 OP/ED 분석 반영.
- TMDB 실패를 제목 없음으로 저장하지 않도록 수정. 정상적인 빈 결과만 30일 보관하고 인증 오류는 30분, 다른 실패는 최소 1분 또는 서버가 지정한 시간 뒤 다시 시도합니다. 영어 애니메이션 ID·한국어 제목·명명된 시즌과 다른 시즌의 별칭 제외 로직을 반영했습니다.
- 기존 설정·기록·자막·API 키 보존. iOS의 설치·Metal/CPU·파일 앱·전체 화면 방식은 이식 목록에 명시하며, 릴리즈에는 IPA와 SideStore 소스만 게시합니다.

- 세부 코드 대조의 11건 수정: 수동 로컬 번역 API 대체 차단, 실제 모델 프롬프트·문맥·정리·재시도, 명시적 탐색 우선 번역, 링크애니 내장 한국어 구분.
- 다운로드 실패를 회차당 한 번 집계하고 늦은 콜백을 무시합니다. 토큰이 갱신된 HLS는 같은 목록의 완료 조각을 이어받습니다.
- PNG 헤더·패딩이 붙은 영상 조각을 64KiB 범위에서 찾아 재생·다운로드·Cast에 연결하며, 일반 암호화 조각은 보존합니다.
- 자막 검색 실패 캐시를 재시도 가능하게 정리하고, 현재 자막 폰트만 복사하며, 20개 보관 한도에서 새 백그라운드 자막을 유지합니다.
- TMDB 요청 간격/429 대기 공유·Retry-After·일시 오류 재시도 및 실패 원인별 제목 수집 재시도.
