# 0.4.0 iOS 리비전 5

Android와 같은 **0.4.0**, iOS 빌드 **35**입니다.

- 플레이어 설정을 영상 위 오른쪽 패널로 변경했습니다. 데스크탑처럼 재생·자막·자막 모양 탭과 화질·배속·화면 비율 선택 버튼을 사용합니다.
- iPad 맞춤·채움·늘림이 화면 비율에 가려지던 문제를 수정했습니다. 원본 비율 유지, 가장자리 자르기, 화면 전체 늘리기가 각각 적용됩니다. 화면 모드를 선택하면 이전 비율 설정도 함께 정리합니다.
- 데스크탑처럼 새 설치의 OP/ED 건너뛰기 버튼은 켜짐, 자동 건너뛰기는 꺼짐입니다. 기존 사용자가 저장한 선택은 유지합니다.
- 설정의 로컬 GGUF 모델 화면에서 뒤로 가기와 홈·메뉴 이동을 수정했습니다. 다른 화면으로 이동하면 설정 하위 화면도 닫힙니다.
- 배속 3x/4x, 건너뛰기 버튼 표시 설정, 0.25초 자막 타이밍 조절과 파일 앱 글꼴 가져오기를 설정 패널에 추가했습니다.
- 기존 설정·기록·자막을 보존하며, 새 필드는 이전 설정 파일에서도 읽을 수 있습니다.

# 0.4.0 iOS 리비전 4

Android와 같은 **0.4.0**, iOS 빌드 **34**입니다. 데스크탑 0.5.6과 로컬 후속 커밋의 변경을 반영했습니다.

- 전체 카탈로그에서 소스별 장르·형식·연도·분기를 적용/초기화하고 소스 전체 목록을 조회합니다. 정렬 API와 다음 페이지 탐색을 보완했습니다.
- 재생 중 영상을 0.4초 이상 꾹 누르면 2배속, 손을 떼면 원래 배속으로 복원합니다. 외부 키보드 Space도 짧게 누르면 재생·일시정지, 길게 누르면 2배속입니다.
- 원본/16:9/21:9/4:3/화면 채움 비율 선택과 자막 싱크 밀리초 직접 입력·초기화, 일반 텍스트 자막 표시 폭 조절.
- iPad에서 사이드바를 기본으로 표시하고 검색창 왼쪽 메뉴 버튼으로 다시 열 수 있습니다. 좁은 창에서는 메뉴가 열립니다.
- 기존 즐겨찾기·시청기록·설정·자막 싱크·API 키·수동 모델을 보존합니다. 릴리즈에는 IPA와 SideStore 소스만 게시합니다.

# 0.4.0 iOS 리비전 3

기존 기능까지 데스크탑 화면·동작 기준으로 재구성했습니다. 이전 버전은 기존 릴리즈에서 받을 수 있습니다.

- 기본 홈/전체/검색/시청기록/내 목록/설정, 공통 검색창과 설정 7개 분류.
- 홈 추천·요일/시즌/방영 중 목록·전체 보기, 검색 필터 적용/초기화, 소스별 정렬 기억, 시청기록 선택 삭제.
- 모든 재생을 가로 전체 화면으로 통일하고 확대/해제 버튼 제거. 재생·자막·자막 모양 설정은 플레이어 안에서 엽니다.
- PC 다운로드 목록과 영상·자막·폰트·OP/ED 가져오기. 목록 비우기 시 파일 보존 및 다시 찾기.
- Gemini 일별/분당 quota, Qwen 무료 quota, busy/timeout 모델 전환 대기 시간을 데스크탑과 맞춤.
- 새 설치 기본 소스 ReAnime, 기존 소스 선택 보존.
- 기존 설정·즐겨찾기·시청기록·자막·API 키 보존. Android와 같은 0.4.0 버전, iOS 빌드 33.

# 0.4.0 iOS 리비전 2

Android와 같은 앱 버전 **0.4.0**, iOS 빌드 **32** (v0.4.0-ios.2)입니다.

LilacAnime-desktop 0.5.5의 전체 기능군을 iOS 네이티브 구조로 이식했습니다.

- 기존 탭 UI·보관함·설정·기록·자막 싱크 보존; 선택형 데스크탑 사이드바와 iPad 화면.
- 전체 카탈로그·한국어/영어 제목·별칭 검색, TMDB/AniList/Wikidata, 한국어 소개·등장인물 표기.
- 소스별 방영/추천/필터, 관련 작품·조회 통계, 서버·화질 선택 보존.
- 제작자·Naver/Tistory/Blogger 첨부·Jimaku, 시즌 누적 회차, ZIP/7z/지원 RAR 자막과 폰트.
- 회차별 원본/번역 자막 보관·공유, 재생 장면 우선·다음 화·다운로드 자막 번역, 캐시 재개/재번역, 등장인물/호칭/용어집.
- 번역 API 연결·모델 목록·제공자별 모델, 오류 재시도/대체.
- 데스크탑 GGUF 모델 프리셋 받기·취소·이어받기, llama.cpp b11490·실제 Jinja·Thinking·Metal/CPU·실행 정보.
- 다운로드 전체 관리·오프라인 OP/ED 분석·영상/자막/폰트/분석 정보를 폴더로 내보내기·가져오기.
- 플레이어 음량/음소거/화면 맞춤·외부 키보드 단축키, 릴리즈 자동 확인·IPA 다운로드/공유.

**설정 → 데스크탑 작업 공간**에서 새 사이드바를 켭니다. 기존 탭 화면은 끄면 돌아옵니다.
LilacAnime-SideStore.ipa는 압축을 풀지 않고 SideStore로 가져옵니다. **기존 앱을 삭제하지 말고** 같은 앱으로 업데이트하세요.
