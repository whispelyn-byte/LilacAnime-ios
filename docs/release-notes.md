Android 원본과 동일한 **0.4.0 (빌드 30)** 버전입니다.

홈·상세 UI, Android 구성을 참고한 플레이어, 자막·번역·다운로드·Cast 기능을 포함합니다. 직접 영상 URL 입력란을 제거했습니다.
