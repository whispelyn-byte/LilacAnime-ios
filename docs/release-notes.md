- 영상 서버·화질을 바꿔 재생을 다시 연결해도 AI 번역 자막의 표시 스타일을 유지합니다. 아직 번역 중인 임시 자막에도 적용됩니다.
- 데스크탑 최신 버전의 작품 정보·회차·자막 게시물 병렬 요청, 같은 작품 정보 요청 공유, 애니24 영상 직접 조회와 실패 시 웹 조회를 반영했습니다.
- FlixCloud 영상 조각의 첫 요청 크기를 줄이고, 데이터 수신이 멈춘 요청을 다시 보내도록 개선했습니다.
- GGUF 가져오기, 앱 시작 시 저장 목록 복원, 작품 검색, 자막 한국어 판별, 자막 캐시 정리의 무거운 작업을 백그라운드로 옮겼습니다. 이전 자막의 판별 결과가 새 선택에 적용되지 않도록 처리했습니다.
- AI 번역 자막을 데스크탑처럼 일반 WebVTT와 기본 글꼴로 표시합니다. 원본 ASS의 특수 스타일을 제거하며 직접 설정한 글꼴·크기·테두리·위치는 유지합니다.

# 0.4.0
Android 원본과 같은 앱 버전 **0.4.0**, iOS 빌드 **39**입니다. 기존 설정·즐겨찾기·시청 기록·다운로드를 보존합니다.

데스크탑 화면 동작을 다시 대조했습니다. 플레이어의 자막 칩을 누르면 그 자막이 바로 적용되고 Jimaku·사이트 트랙·Anissia 제작자 목록이 패널 안에 나옵니다. 영상 서버는 종류별로 묶고 자동을 추가했으며, 회차 목록 페이지·최신화순·더빙/방영일 표시, 회차 다운로드 버튼 상태, 다운로드 작품별 일괄 동작, 검색의 다른 언어 제목 합치기, 시청기록 재생 시 새 회차 반영, 음량 기억을 추가했습니다. 자세한 내용은 [테스터 제보 수정](tester-fixes.md#데스크탑-화면-동작-재대조)에 있습니다.
